# Data Directory

```
data/
├── raw/            ← Place CIC-DDoS2019 CSV files here (gitignored)
├── processed/      ← Cleaned DataFrames after preprocessing (gitignored)
├── splits/         ← Train/val/test splits as .npy or .parquet (gitignored)
├── synthetic/      ← Synthetic dataset generated by scripts/ (gitignored)
└── alerts.db       ← SQLite alert database created by API at runtime
```

## CIC-DDoS2019 Dataset

Register and download from:  
https://www.unb.ca/cic/datasets/ddos-2019.html

Expected files in `data/raw/`:
```
UDPFlood.csv
TCPFlood.csv
ICMP.csv
SlowLoris.csv
HTTPFlood.csv
Benign.csv        (or Friday-WorkingHours-Afternoon-Infilteration.pcap_ISCX.csv)
```

## Synthetic Data (No Registration Required)

```bash
python scripts/generate_synthetic_data.py --n-samples 20000
# → data/synthetic/synthetic_ddos.csv
```

Then train with:
```bash
python model/train.py --use-synthetic
```

## Data Privacy Note

**Never commit real network captures or CSV files containing IP addresses.**  
All `data/raw/`, `data/processed/`, and `data/splits/` paths are in `.gitignore`.
